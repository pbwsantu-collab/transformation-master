# 🔄 Transformation Master AI

**Professional bilingual (English + Bengali) Progressive Web App for mastering Transformation of Sentences.**

Designed for **West Bengal Board** students (Classes V–XII), Madhyamik & Higher Secondary.

## Features

- 📚 Structured lessons covering all major transformation types
- ✍️ Interactive practice with free-text answer checking
- 🎯 Smart Quiz mode
- 📝 Question Bank extracted from standard Higher English Grammar textbooks
- 📊 Progress tracking (local)
- 👨‍🏫 Teacher Zone – Question Paper Generator + Print/PDF
- 🌐 Bilingual support (English / বাংলা / Both)
- 🌙 Dark / Light theme
- 📱 Mobile-first PWA (installable + offline capable)

## Topics Covered

- Interchange of Degrees of Comparison
- Affirmative ↔ Negative
- Assertive ↔ Exclamatory
- Assertive ↔ Interrogative
- Simple ↔ Complex ↔ Compound
- Interchange of Parts of Speech
- Miscellaneous transformations

## How to Run

```bash
# Simple local server
python3 -m http.server 8080
# Then open http://localhost:8080
```

Or open `index.html` directly in a modern browser.

## Tech Stack

- Pure HTML / CSS / JavaScript
- Progressive Web App (manifest + Service Worker)
- LocalStorage for progress
- No build step required
